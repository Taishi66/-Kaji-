> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compression 0-token des tool-results de l'historique dans la vue envoyée au provider (jamais la session stockée) — spec `docs/superpowers/specs/2026-08-11-condense-design.md`.

**Architecture:** Module pur `context_mgmt/condense.rs` (transform + stats + totaux atomiques) ; **une seule insertion** dans `stream_response_from_provider` (`agents/reply_parts.rs:329`), la fonction partagée où convergent les chemins legacy (`agent.rs:2387`) et state-machine (`ops_llm.rs:473`) → parité par construction. Raffinement vs spec (qui disait « deux points d'injection ») : même intention, moins de code, parité plus forte — acté.

**Tech Stack:** Rust, crates/kaji (+ ligne /cost dans crates/kaji-cli). Pas de nouvelle dépendance (regex si déjà dans les deps de kaji, sinon scan manuel ANSI).

## Global Constraints

- La conversation de session (persistée) n'est JAMAIS modifiée — la transform ne touche que la copie sortante.
- Le tour courant + `keep_raw_turns` (défaut **2**) derniers messages user-texte restent bruts.
- Env vars : `KAJI_CONDENSE` (défaut actif ; off si `0|false|FALSE|no` — idiome `state_machine::enabled()`, mod.rs:56), `KAJI_CONDENSE_KEEP_TURNS` (défaut 2), `KAJI_CONDENSE_MAX_LINES` (défaut 40) via `Config::global().get_param` (zéro/invalide → défaut, pattern agent.rs:806/816).
- Marqueur exact : `[… {N} lignes omises — résultat complet conservé en session]`.
- Head = `max(1, max_lines*60/100)` lignes, tail = `max(1, max_lines*25/100)` ; sortie ≤ head+tail+1 lignes.
- Idempotence : recondenser une sortie condensée = no-op (et stats non double-comptées).
- Baseline : `kaji --lib` 8 échecs préexistants inchangés ; clippy workspace `--all-targets -D warnings` reste VERT (il l'est depuis `df69bd08b`).
- Un commit par tâche, message `kaji: condense — …` + trailer `Claude-Session: https://claude.ai/code/session_014ngoE4sNSgzrZPdgb7qC2r`.

```rust
// crates/kaji/src/context_mgmt/condense.rs
use crate::config::Config;
use crate::conversation::message::{Message, MessageContentBlock};
use std::collections::BTreeMap;
use std::sync::atomic::{AtomicU64, Ordering};

pub const DEFAULT_KEEP_RAW_TURNS: usize = 2;
pub const DEFAULT_MAX_LINES: usize = 40;
const OMISSION_MARKER: &str = "lignes omises — résultat complet conservé en session";

pub fn enabled() -> bool {
    !std::env::var("KAJI_CONDENSE").map(|v| matches!(v.as_str(), "0" | "false" | "FALSE" | "no")).unwrap_or(false)
}
pub fn keep_raw_turns() -> usize {
    match Config::global().get_param::<usize>("KAJI_CONDENSE_KEEP_TURNS") { Ok(v) if v > 0 => v, _ => DEFAULT_KEEP_RAW_TURNS }
}
pub fn max_lines() -> usize {
    match Config::global().get_param::<usize>("KAJI_CONDENSE_MAX_LINES") { Ok(v) if v > 0 => v, _ => DEFAULT_MAX_LINES }
}
```

Corps (logique exacte) :

1. `cutoff_index(messages, keep_raw_turns)` : parcours arrière ; un message est frontière de tour si `role == User` && au moins un bloc `Text` && aucun bloc `ToolResponse` ; retourner l'index de la `keep_raw_turns`-ième frontière depuis la fin (ou `0` s'il y en a moins → rien à condenser).
2. Première passe : map `id → nom` depuis tous les blocs `ToolRequest` (`req.tool_call` porte le nom — vérifier le champ exact dans message.rs ; fallback `"?"`).
3. `messages[..cutoff]` : pour chaque bloc `ToolResponse` avec `Ok(result)`, reconstruire `result.content` en passant chaque `ContentBlock` texte (`as_text()`) par `condense_text` ; blocs non-texte et variantes non-ToolResponse intacts. Patron exact de reconstruction : `filter_for_audience` (message.rs:319-382) et mutation in-place `fix_empty_tool_results` (conversation.rs:399-424) — préférer la mutation in-place sur le clone du Vec de messages.
4. `condense_text(text, max_lines) -> Option<String>` (None = inchangé) : (a) strip ANSI — `regex` si déjà dep de crates/kaji (vérifier Cargo.toml ; pattern `\x1b\[[0-9;?]*[ -/]*[@-~]`, `std::sync::LazyLock`), sinon scan manuel d'échappement ; (b) rtrim par ligne ; (c) dédup lignes consécutives identiques non-vides → `ligne ×N` ; (d) si nombre de lignes > max_lines : `head = max(1, max_lines*60/100)`, `tail = max(1, max_lines*25/100)`, sortie = head lignes + `[… {omises} {OMISSION_MARKER}]` + tail lignes. Retourner None si le résultat final est identique à l'entrée.
5. Stats : incrémenter uniquement quand `condense_text` retourne `Some` ; totaux : `record_totals` sur 3 `AtomicU64` statiques, `totals()` les lit.
