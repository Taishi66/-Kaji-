## Global Constraints

- Spec = source de vérité pour chaque comportement (défaut thinking OFF, loader `{ensō} 思考中 · {N}s` frames `◐◓◑◒`, molette ×3 lignes, lame `▊▋▌▍` VERMILLON, marge 1 col, triple mapping delete-word Ctrl+Backspace/Alt+Backspace/Ctrl+W).
- `KAJI_MOUSE` défaut actif, off ssi `0|false|FALSE|no` (idiome `condense::enabled`).
- `DisableMouseCapture` doit s'exécuter aussi sur les chemins d'erreur (le pattern restore existant de tui::run — l'étendre, pas le dupliquer).
- La mesure (wrapped_rows/chat_overflow/offsets de tours) reste cohérente avec la largeur réellement rendue (marge comprise) — invariant du fix scroll `5288cb033`.
- Baseline kaji-cli verte (366 tests au départ) + nouveaux ; clippy scoped `-D warnings` ; fmt ; un commit par tâche `kaji: tui — …` + trailer `Claude-Session: https://claude.ai/code/session_014ngoE4sNSgzrZPdgb7qC2r`.
